These files are the online quiz pages for the QR codes.

To make the QR codes fully valid for submission:
1. Upload this QuizPagesToHost folder to a public web host, GitHub Pages, Google Sites, or another online location.
2. Copy the public URL for each level page.
3. Edit BuildScripts/quiz_links.txt with the real URLs.
4. Run: bash BuildScripts/build_game.sh
5. Use the regenerated CryptoEscapeGame folder for the demo and screenshots.

The current QR codes use placeholder GitHub Pages style URLs, because this environment cannot publish Google Forms, Kahoot, or web pages on your behalf.
